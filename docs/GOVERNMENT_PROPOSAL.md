## Subject

Adoption of the BOSC Community Library as an open source education resource platform.

## Background

I am proposing the BOSC Community Library as a public education resource project that can support schools, teachers, learners, and community study groups. The project was developed from an open source software perspective as part of my Bachelor of Science in Software Engineering work at Bugema University. Its main idea is simple: educational resources should be easier to find, review, adapt, and share without forcing every institution to depend on expensive proprietary platforms.

## Why Open Source Fits Public Education

Public education systems need transparency and long-term control. When a ministry or school uses a closed proprietary platform, it may not fully control the data, the resource format, the upgrade process, or the future cost. An open source repository like BOSC Community Library gives the Ministry the ability to inspect the work, adapt it to local needs, and invite teachers, universities, and developers to improve it through a public process.

## Total Cost Of Ownership

The cost of proprietary software is not only the first payment. There can be subscription fees, user limits, training costs, renewal fees, and extra charges for support. These costs become a problem when schools have limited budgets. BOSC Community Library reduces total cost of ownership because the core project is free to use and modify. Money can be spent on useful local needs such as teacher training, offline access, content review, and support instead of repeated license payments.

## Vendor Lock-In

Vendor lock-in happens when an institution becomes dependent on one supplier and cannot easily move away. This can happen when data is stored in closed formats or when only one company can provide updates. BOSC Community Library avoids this by using open files, public documentation, GitHub issues, and an Apache 2.0 license. If one service provider becomes expensive or stops supporting the project, the Ministry can continue with another provider because the source remains available.

## Local Relevance

For Uganda, many schools still face challenges such as limited internet access, shared computer labs, and different local language needs. A public open source library can be adapted gradually instead of waiting for one vendor to solve every problem. Teachers and university students can help improve categories, add local examples, and review resources for accuracy.

## Recommended Pilot

The Ministry can begin with a pilot in selected schools or districts. The pilot should test whether teachers can find resources easily, whether the catalogue works under low-bandwidth conditions, and whether local language summaries are useful. Feedback should be tracked as GitHub issues and resolved through pull requests so that the whole process remains transparent.

## Conclusion

BOSC Community Library offers a transparent and affordable alternative to proprietary education platforms. It protects public investment by keeping the main resource catalogue open, reviewable, and adaptable. With proper governance and support, it can help schools access useful learning materials while reducing long-term dependence on one vendor.
