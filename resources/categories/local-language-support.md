# Local Language Support
Local language support helps contributors add translated summaries, local examples, and culturally relevant descriptions.

## Included Resources

### Local Language Contribution Guide

- Provider: BOSC Maintainers
- License: CC BY 4.0
- Audience: Teachers and translators
- Connectivity: Low bandwidth
- Summary: Guidance for adding translated summaries and local examples while preserving original meaning and attribution.

## Translation Rules

- Keep the original title and attribution.
- Add the local language summary below the English summary.
- Identify the language used.
- Ask for review from a speaker of the language where possible.
- Do not translate copyrighted material unless the license allows adaptation.
