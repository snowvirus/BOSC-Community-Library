# Governance Directory

The `governance/` directory contains the rules and workflow expectations for contributors and maintainers.

## Files

- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) defines respectful behavior and reporting expectations.
- [CONTRIBUTING.md](CONTRIBUTING.md) explains how to open issues, create branches, submit pull requests, and review changes.

## Contributor Workflow

1. Check existing issues before starting.
2. Create a focused branch from `main`.
3. Make a small change linked to one issue.
4. Open a pull request using the repository template.
5. Add review evidence before merge.
6. Use a closing keyword such as `Closes #5` in the pull request body when the work should close an issue after merge.

## Maintenance Notes

- Keep behavior rules in `CODE_OF_CONDUCT.md`.
- Keep technical contribution steps in `CONTRIBUTING.md`.
- Update this directory when the project workflow changes.
